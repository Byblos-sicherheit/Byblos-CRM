- Lizenz: Apache License 2.0
- Bezugsquelle: `caddy:2.11.4-alpine`
- Dokumentation: https://caddyserver.com/docs/

## Docker / Docker Compose

- Nutzung: Container-Ausführung und Orchestrierung
- Installation und Lizenzbedingungen: https://docs.docker.com/

  Backup-/Restore-Befehlen
- Image-Tags: über das Caddy-Image sowie `alpine:3.22`
