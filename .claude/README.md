# .claude — Byblos Claude Code Konfiguration

Diese Verzeichnisstruktur enthält alle installierten Claude Code Skills, Commands und Agents
für das Byblos Sicherheit & Facility Services Projekt.

## Struktur

```
.claude/
├── skills/                          # Claude Code Skills
│   ├── universal-programmer-mind/   # Vollständiger Engineering-Workflow

│   ├── mattpocock/                  # 37 Dev-Workflow-Skills

│
├── commands/                        # Slash-Befehle (260+ Commands)

│   ├── deploy/                      # CI/CD & Deployment

│   └── ...
│
└── agents/                          # Spezialisierte KI-Agenten (86+)
```
