# Develocity Current Snapshot — 2026-07-27

This is a dated research snapshot, not permanent product truth. Refresh all claims from official sources before external use.

## Verified official positioning

- Develocity positions itself as a context-engineering layer for software delivery that combines governance and efficiency for humans and AI agents.
- The platform describes Build Scan as the foundational dataset for build tasks, tests, dependencies, cache decisions, resource use, and environment context.
- The AI solution describes provenance and policy evidence for AI-generated artifacts, accelerated feedback loops, machine-readable context through MCP servers, and controls for rising CI cost.
- The DORA solution maps Universal Cache, Predictive Test Selection, Test Distribution, Flaky Tests Detection, and continuous policy controls to speed and stability outcomes.

## Release and lifecycle facts to verify during implementation

- The latest release listed on the official release page on 2026-07-27 was Develocity 2026.2, dated 2026-06-30.
- The official 2026.2 highlights included Build Caching Optimizer, Repository Stability visibility, expanded Artifact Cache coverage, Setup Cache enhancements, and Provenance Governor enhancements.
- Current documentation states that support for the legacy Develocity Build Cache node component is planned to end after 2026, with Develocity Edge recommended as the migration path. Confirm the current lifecycle notice before designing topology.

## Commercial fact to verify

- The public pricing page states that pricing is per committer, per year, with capabilities packaged separately and some requiring the Observability Platform. Obtain a current quote and validate package dependencies; do not infer price from the public page.

## Quantitative vendor claims

The official pages may publish figures such as Artifact Cache serving more than 95% of artifacts from cache or named customer savings. Treat these as vendor-reported or case-specific evidence. Do not use them as the organization's forecast.
