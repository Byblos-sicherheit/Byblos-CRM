# Change taxonomy

## High-impact changes

- Free tier removed or converted to trial.
- Quota reduced, duration shortened, or eligibility narrowed.
- Card or billing account newly required.
- Automatic overage or paid conversion introduced.
- TLS, custom domain, export, backup, or security control moved behind paid tier.
- Commercial use, region, data residency, or open-source-only restriction added.
- Inactivity suspension or resource reclamation introduced.

## Medium-impact changes

- Quota increased.
- Product renamed or moved to a new domain.
- Category moved.
- Support or retention terms changed.

## Low-impact changes

- Grammar, punctuation, or marketing wording.
- Tracking parameters or harmless URL normalization.
- Description reordered without material term changes.

## Common false positives

- Provider rebrand creates one removal and one addition.
- Homepage URL changes to a pricing URL.
- Markdown link text changes while the service remains identical.
- A nested cloud product line changes inside a parent provider entry.
