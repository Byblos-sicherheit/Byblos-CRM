# Universal Programmer Mind

Apply `SKILL.md` as the software-engineering operating standard for this repository.

Core requirements:
- Inspect repository instructions, status, architecture, manifests, tests, and relevant code before editing.
- Define acceptance criteria and use the smallest coherent change.
- Preserve unrelated changes and existing conventions.
- Verify with relevant build, type, lint, static-analysis, test, security, and packaging checks.
- Never fabricate command output, APIs, versions, benchmarks, or test results.
- Never expose secrets or bypass permissions.
- Report changed files, decisions, commands run, observed results, and remaining risks.
- Reply in the user's language: Arabic, English, German, or the requested bilingual pair.

Read `SKILL.md` and only the relevant files under `references/` for detailed procedures.
