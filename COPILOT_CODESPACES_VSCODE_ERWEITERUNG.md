# Erweiterung: skills-copilot-codespaces-vscode

## Was wurde ergänzt

- GitHub Codespaces Devcontainer
- VS Code empfohlene Extensions
- VS Code Tasks für Install, Start, Smoke-Test und Windows-Build
- Debug-Konfiguration für Streamlit
- GitHub Copilot Instructions
- GitHub Actions Smoke-Test
- lokale Setup-Skripte für Windows und macOS/Linux
- Dokumentation unter `docs/devops/COPILOT_CODESPACES_VSCODE.md`

## Warum das wichtig ist

Das CRM ist inzwischen groß. Ohne reproduzierbare Entwicklungsumgebung riskierst du Fehler durch unterschiedliche Python-Versionen, fehlende Pakete und manuelle Build-Schritte. Diese Erweiterung macht den Einstieg wiederholbar.

## Noch extern nötig

- GitHub Repository anlegen
- Codespaces in GitHub aktivieren
- GitHub Copilot Lizenz/Account aktivieren
- finale Produktiv-Tests auf Windows/Android
